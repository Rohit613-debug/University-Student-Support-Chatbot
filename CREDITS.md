
# Source Code Credits and Acknowledgments

## Project
University Student Support Chatbot

University of the Cumberlands
MSAI-631: Artificial Intelligence for Human-Computer Interaction

## Original Project Implementation

The group assembled and adapted the chatbot application
using Python, Flask, HTML, CSS, and JavaScript.

The implementation includes a browser-based chat
interface, a Flask backend, and a question-answering
component based on TF-IDF and cosine similarity.

## AI-Assisted Development

OpenAI ChatGPT was used to assist with:

- Generating initial Python, HTML, CSS, and JavaScript code
- Troubleshooting file placement and import errors
- Explaining Flask and Python environment configuration
- Developing the chatbot question-matching logic
- Preparing setup instructions and documentation
- Suggesting testing and debugging procedures

Generated code was reviewed, adapted, and tested
locally during development.
